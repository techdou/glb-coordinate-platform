# 标注和上传流程

## 1. 准备素材

把模型放到：

```text
app/assets/models/
```

把参考图、PDF、流程图放到：

```text
app/assets/references/
```

把构筑物清单整理到：

```text
app/data/structures_named.json
```

## 2. 本地标注

```powershell
cd E:\projects\glb-coordinate-platform
.\scripts\start.ps1
```

在浏览器中打开页面后：

1. 确认模型自动加载。
2. 确认左侧清单自动加载。
3. 在“采集模式”下选择构筑物名称。
4. 在模型对应位置单击。
5. 全部点完后点击“导出完整工程”。

## 3. 上传渲染平台

上传两类文件：

- `app/assets/models/*.glb`
- `coordinate_project_*.json`

平台加载时按 `structures[*].center` 放置标注。不要把这些坐标当成屏幕坐标，也不要当成经纬度；它们是 GLB 局部坐标。

## 4. 抽样验证

上传后至少抽查：

- 一个左上/左前区域的点。
- 一个右下/右后区域的点。
- 一个高处或罐体顶部点。
- 一个靠近模型边界的点。

如果这些点都对，基本可以判断原点、缩放、旋转没有被破坏。

## 5. 常见问题

### 点位整体偏移

通常是平台加载模型后又移动了根节点。解决方法是：标注跟随模型根节点，或者对点位应用同样的模型变换。

### 点位整体变大或变小

通常是平台对模型做了缩放。解决方法是：保持模型根节点 `scale = [1,1,1]`，或者同步缩放点位。

### 换了新模型后点位不准

如果新模型改变了原点、比例、旋转或几何布局，旧坐标就不能直接复用，需要重新标注或写迁移脚本。
