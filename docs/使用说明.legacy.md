# 通用 3D 坐标采集工具

这个目录里的 `index.html` 已经封装成通用坐标采集工具：加载任意 GLB/GLTF 模型，再加载或粘贴一组名称，逐项在 3D 模型上点选位置，最后导出：

```json
{
  "构筑物名称": [x, y, z]
}
```

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `index.html` | 通用 3D 坐标采集页面 |
| `modelToUse.glb` | 当前示例 3D 模型 |
| `structures_named.json` | 当前示例的 19 个构筑物名称清单 |
| `clusters_topdown.png` / `俯视图.jpg` / `侧视图.png` | 辅助人工识别位置 |

## 启动方式

必须用本地 HTTP 服务打开，不能直接双击 HTML。直接双击会触发浏览器的本地文件安全限制，导致 JSON 或 GLB 读取失败。

```powershell
cd C:\Users\DouXiulu\Desktop\temp
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/index.html
```

## 使用流程

1. 打开页面后，工具会自动尝试加载当前目录的 `modelToUse_compressed.glb` 或 `modelToUse.glb`。
2. 如果没有自动加载，点击 `选择 GLB 模型` 手动选择模型。
3. 名称列表会自动尝试读取 `structures_named.json`；也可以点击 `导入 JSON 清单` 或 `粘贴名称列表`。
4. 在 `采集模式` 下，点击左侧构筑物名称。
5. 在 3D 模型对应位置单击一次，工具会记录该名称的 `[x,y,z]`，并自动跳到下一个未采集名称。
6. 19 个都点完后，点击 `导出坐标 JSON`，得到 `{名称: 坐标}` 格式文件。

## 支持的清单格式

一行一个名称：

```text
预处理及进水在线监测用房
水解酸化池
高效厌氧反应器及泥水分离系统
```

字符串数组：

```json
["预处理及进水在线监测用房", "水解酸化池"]
```

对象数组：

```json
[
  { "name": "预处理及进水在线监测用房" },
  { "name": "水解酸化池", "center": [0.1, 0.2, 0.3] }
]
```

完整工程格式：

```json
{
  "structures": [
    { "name": "预处理及进水在线监测用房", "center": [0.1, 0.2, 0.3] }
  ]
}
```

名称到坐标的映射：

```json
{
  "预处理及进水在线监测用房": [0.1, 0.2, 0.3],
  "水解酸化池": null
}
```

## 稳健性优化点

- 导出坐标使用 GLB 模型局部坐标，不受页面为了居中显示模型而做的场景平移影响。
- 鼠标拖动旋转视角不会误触发采点；只有短距离单击才记录坐标。
- 自动保存浏览器本地草稿，刷新页面后可继续。
- 支持导入已有坐标，继续补采未完成点位。
- 支持 `导出坐标 JSON` 和 `导出完整工程` 两种格式。
- 支持 Fit、Top、Iso 视角快速定位。

## 坐标有效范围

坐标不是跨模型通用的，它只绑定到同一个 GLB 的局部坐标系。通俗说，坐标像“楼里的房间号”，同一栋楼里有效；如果楼整体搬了、缩放了、重新编号了，旧房间号就可能找不到原位置。

有效条件：

- 使用同一个 GLB，或只做不改变原点、缩放、旋转和几何位置的压缩。
- 业务系统加载模型时不额外改变模型坐标系。

失效条件：

- 重新导出模型时改了原点、缩放、旋转或整体位置。
- 模型版本变化，构筑物位置变化。
- 把旧版工具采集的“页面居中后的场景坐标”直接当成新版“GLB 原始局部坐标”使用。

如果导入优化前工具打的点后位置跑偏，先加载原来的 GLB，再点击页面里的 `迁移旧版坐标`。迁移后切到 `浏览模式`，抽查几个点确认无误，再重新导出。

注意：工具不能自动判断当前 JSON 一定是旧版坐标。迁移前会保存一份浏览器本地备份；如果抽查发现不对，点击 `撤销迁移` 恢复。
